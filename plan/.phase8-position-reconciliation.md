## Completed implementation

- Track quantity, average/entry price, current price, target price, sellability and lifecycle status in the provider-neutral position contract.
- Rebuild slot/capital ownership deterministically from authoritative position state after restart.
- Detect missing, unexpected and ambiguous positions; fail closed where truth is unclear.
- Keep reconciliation provider-neutral and prevent live order submission from reconciliation itself.
- Add deterministic tests for converged, missing, unexpected, ambiguous, restart-recovery and authoritative projection states.
- Align Phase 8 reconciliation specs with the canonical native `node:test` backend test runner so the deterministic suites do not depend on an undeclared Vitest runtime.
