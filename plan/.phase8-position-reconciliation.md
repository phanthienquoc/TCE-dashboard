# Phase 8 — Position Reconciliation

Status: IN PROGRESS
Issue: #496
Phase branch: `phase/tce-auto-trade-phase-8-position-reconciliation`

## Objective
Establish authoritative, restart-safe position truth for downstream dividend lifecycle and automatic take-profit execution.

## Required implementation
- Normalize provider holdings into provider-neutral TCE position state.
- Reconcile local positions with provider truth deterministically.
- Track quantity, average/entry price, current price, target price, sellability and lifecycle status.
- Rebuild slot/capital ownership from authoritative order/position state after restart.
- Detect missing, unexpected and ambiguous positions; fail closed when truth is unclear.
- Keep reconciliation provider-neutral and prevent live order submission from reconciliation itself.
- Add deterministic tests for converged, missing, unexpected and ambiguous states.

## Dependency
Phase 8 must be complete before Phase 10 automatic +5% exit can safely create EXIT_READY/SELL intents from authoritative HOLDING positions.
