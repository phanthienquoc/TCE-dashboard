# Phase 8 — Position Reconciliation / Task #495

**Status:** IN PROGRESS

## Objective
Restore the roadmap frontier after Phase 7 and establish authoritative position truth as the dependency for automatic stock take-profit exits.

## Scope
- Normalize broker/provider holdings into the existing TCE position contract.
- Reconcile local positions against authoritative provider positions.
- Track current price, average/entry price, quantity, status, sellability and target.
- Rebuild slot/capital ownership from authoritative state after restart.
- Detect missing, unexpected/manual and ambiguous positions without unsafe mutation.
- Provide deterministic position truth to downstream Phase 10 exit logic.
- Keep provider-specific details behind the existing adapter/reconciliation boundaries.

## Acceptance criteria
- Position reconciliation is deterministic and restart-safe.
- Unknown/ambiguous provider state fails closed.
- Position state is authoritative before an exit can be created.
- No live order submission is performed by reconciliation itself.

## Dependency chain
Phase 7 Order Reconciliation → Phase 8 Position Reconciliation → Phase 9 Dividend/T+2 → Phase 10 Exit/Take Profit +5% → Phase 11 Slot Recycle → Phase 12 Persistence/Audit → Phase 13 Reliability/Idempotency → Phase 14 Runtime/Scheduler.
