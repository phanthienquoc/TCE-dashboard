# Phase 7 Task #464 — Local Order ↔ SSI State Reconciliation

## Objective
Provide a deterministic, provider-neutral reconciliation core that compares local orders with SSI truth.

## Scope
- Match by provider order id, with client request id as fallback.
- Detect missing provider orders.
- Detect orphan provider orders.
- Converge recognized partial-fill and terminal provider states as reconciliation dispositions.
- Treat unknown provider states as `RECONCILIATION_REQUIRED` and never silently mutate local state.
- Keep persistence, lifecycle events, and automatic resubmission out of this task.

## Verification
- Deterministic Node test coverage for matching, partial fills, terminal states, unknown states, missing orders, and orphan orders.
- Task branch must be reduced to exactly one clean commit before PR.
- Merge target is Phase 7 only; Phase 7 → master remains a separate promotion step.
- CI is informational/non-blocking.
